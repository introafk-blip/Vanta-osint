# VANTA - Windows

Рабочее место OSINT-аналитика: граф связей, досье, отчёт, карта, публикация.
Один exe, без установки. Внутри — Electron-оболочка и вся логика приложения.

## Скачать

| Файл | Размер | Что это |
|------|--------|---------|
| `VANTA-1.0.0-win64.exe` | 71,4 МБ | Портативная сборка. Запускается двойным кликом. |

Проверка целостности: `SHA256SUMS.txt` (Windows: `certutil -hashfile VANTA-1.0.0-win64.exe SHA256`).

## Требования

- Windows 10 или 11, 64-бит.
- Интернет — только для карт, панорам и поиска адреса по координатам. Граф, анализ,
  досье, отчёты, экспорт и сохранение работают офлайн.

## Первый запуск

1. Скачать exe в любую папку (например, `D:\VANTA`).
2. Двойной клик. Windows может показать «Windows защитила ваш компьютер» —
   это потому, что файл не подписан платным сертификатом:
   «Подробнее» → «Выполнить в любом случае».
3. Первый запуск занимает ~30 секунд: портативная сборка распаковывает себя
   во временную папку. Каждый следующий запуск — столько же, кэша у portable нет.

Альтернатива без ожидания: распаковать релизный архив и запустить `VANTA.exe`
из папки — но такой архив весит ~230 МБ.

## Где лежат данные

`%APPDATA%\VANTA` — кейсы, находки, настройки, история отмен.
Резервная копия — копия этой папки или экспорт кейса в JSON.
Удаление exe данные не стирает.

## Горячие клавиши

- `F5` — перезагрузить интерфейс
- `Ctrl+Shift+I` — инструменты разработчика (отладка)
- В графе: `Tab` — добавить дочерний узел, `Delete` — удалить, `L` — связать, `P` — режим публикации

## Ограничения

- Сборка не подписана: SmartScreen и некоторые антивирусы могут ругаться, но не стоит бояться, это ложные срабатывания.
- Portable-режим не кэширует распаковку — старт медленный, зато файл один и переносимый.

## Исходники

Приложение — один HTML-файл (`VANTAgraph.html`), собранный в Electron-обёртку.
Библиотеки vis-network, Leaflet и шрифты IBM Plex лежат внутри сборки локально.
